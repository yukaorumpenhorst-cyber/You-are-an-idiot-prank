# You-are-an-idiot-prank
This is an application for pranking your friends, inspired by the computer "malware" "you are an idiot". My version is not designed to damage computers, but only as a joke you can play on your friends that will not cause any harm to the computer.  ⚠️ DO THIS BEFORE THE PRANK ⚠️
The first time the file is run, Windows Defender may say it protected the computer because it is not a verified application. Click on "more information" and then "run anyway". Or it may even say that permission was denied, but just close the window and try to run it again.

RECOMMENDATIONS
To make your friend fall for the prank naturally, rename the application to the name of the browser they use most and also change the icon so that they fall for the prank thinking they are opening the browser.
